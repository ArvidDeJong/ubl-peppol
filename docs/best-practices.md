# Best Practices

- Consult the PEPPOL BIS source first: https://docs.peppol.eu/poacc/billing/3.0/bis/
- Keep country-specific rules separated (BE vs NL).
- Validate output XML in official validators before release.
- Keep invoice and credit-note behavior aligned; see [Credit Notes](credit-notes.md).
- Use consistent file naming in docs (`kebab-case.md`, lowercase).
